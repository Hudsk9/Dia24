# Dia 24

Projeto de um site romântico/comemorativo feito com HTML, CSS e JavaScript.

## Sobre o projeto

O site foi criado para celebrar 7 anos de relacionamento, com duas páginas principais, efeitos visuais, galeria de fotos, carrossel e música incorporada.

## Estrutura

- `pages/` - páginas HTML do site
- `css/` - estilos do projeto
- `js/` - scripts e interações
- `assets/` - imagens e gifs usados no site

## Como abrir localmente

1. Abra a pasta do projeto no VS Code.
2. Inicie um servidor local, por exemplo com a extensão Live Server.
3. Abra `pages/pagina1.html` no navegador.
